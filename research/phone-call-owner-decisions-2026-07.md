## D1 · Phase -1 阈值表签认(阻塞前置门①;最紧)

spike 的"达标判定"必须先由你把数字定死(Codex 坚持:否则止损门形同虚设)。下为**建议值**,可直接采纳或改数:

| 指标 | 建议值 | 说明 |
|---|---|---|
| 接起→占位音首响 | p50 ≤ 1.5s / p95 ≤ 3s | 比桌面宽,含握手 |
| 说完→出声(通话内) | p50 ≤ 1.8s / p95 ≤ 3.5s | 桌面是 1.5/2.5,通话+媒体略放宽 |
| 连续 3 分钟丢帧率 | ≤ 2% | 超则媒体不合格 |
| Wi-Fi↔5G 切换恢复 | ≤ 3s | 断后自动重连 |
| 5% 丢包可懂性 | ASR 回转 WER ≤ 15% | 可复现脚本判定,非主观 |
| 后台恢复(切 App 回来) | ≤ 2s | |
| tailnet 直连率 | ≥ 70% | 低于则依赖 DERP(联动 D7) |
| DERP RTT | ≤ 200ms | 蜂窝兜底路径 |
| 睡眠 8 小时后接通空窗 | ≤ 10s | 含 VPN 重连+预热 |

**[已定]采纳建议值**(样本 ≥20 次/指标、p50/p95 双分位)。owner 2026-07-25 采纳。
