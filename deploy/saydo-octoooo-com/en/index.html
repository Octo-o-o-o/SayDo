    01它是另一个语音聊天机器人吗？

    不是。SayDo 围绕有产出物的项目工作：先理解上下文，通过对话澄清需求，再准备决策包、驱动本地 Agent，并组织验收证据。语音是表达方式，不是产品的全部。

    02我拍板后，它会自动替我交付吗？

    不会把“执行结束”当成“已交付”。当前工作方式强调逐步确认；执行和检查结束后进入待验收。高风险动作、真实合并或对外交付仍有各自的确认边界。这个网页只模拟一轮任务，不执行任何真实操作。

    03现在可以安装什么？语音包含在内吗？

    仓库当前面向 developer / preview。快速安装包提供 daemon 与 Web 控制台，支持 macOS、Windows、Linux，但不包含完整语音 pipeline。先准备已登录的 AI CLI，或 OpenAI 兼容 API 供给；语音管线与源码开发安装另有步骤。安装、启动、首次设置与故障排查，已整理在本站“快速开始”。
    The immutable v0.1.0-rc.13 GitHub Release has passed all six installation smokes across macOS, Windows, and Linux and is ready to use; it does not include the voice pipeline or service installation.

    04手机上看到的演示，等于移动端已全面可用吗？

    不等于。这个官网为手机、平板和桌面分别适配，但页面交互是本地演示，不是已发布产品的逐功能复刻，也不构成远程控制、移动审批或跨设备交付能力的承诺。
