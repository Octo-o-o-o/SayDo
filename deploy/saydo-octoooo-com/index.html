从聊一句，到办完叫你

一个完整的闭环

你只管聊和拍板，重活它来。执行和检查都跑完，它主动叫你验收——你点头，才算交付。

1

开口聊

按住说话，想到哪说到哪。随口一句「帮我记一下」立刻进账。它会带着对你项目的理解，像采访一样一次问一个，把事聊透。

2

就绪决断

它判断火候够了，主动提议开工——而不是让你凭空写一份完整的需求规格。规格是它的产物，不是你的输入。

3

决策包

端出决策包请你拍板：成果预览（做完你会得到什么）、实施计划（每步标好 AI 执行还是需要你配合）、预计花费与封顶，外加一份轻量小样——和计划同源生成的网页预览，先看一眼「最终长什么样」。看着具体的东西说「对 / 不对 / 调一下」，比凭空写需求容易一个数量级。

4

你拍板

看着预览和计划说一句「就这样」，它就放手去办。合并、交付，永远是你拍板才算数。

5

后台执行

在你自己的电脑上跑：独立 git worktree 隔离，主工作区不会被碰；有预算、时长、回合熔断，不会无人值守烧钱。你可以走开。

6

办完叫你

执行和检查都跑完，它主动叫你验收——说「等你验收」，而不是「做完了」。回叫按升级链走：配好语音时它在线开口叫你，没应答再升级为桌面通知和手机推送（ntfy）；免打扰时段只留一条轻推送，过后补叫。

7

验收沉淀

口播摘要加证据视图（diff、测试、决策），按验收标准组织好。你点头，盖章销账；知识与产物留存，下次接着用。

没有它的时候

说过的话，转头就忘；答应的事，不知道办到哪了。该等谁的、谁在办、办得怎么样——全靠脑子记和来回翻聊天记录。

有了说到 →

每件事都有归属和去向，一眼看清：等你拍板的、你欠的动作、AI 正在办的、等外部回音的，四色分明，件件有着落。

为什么不一样

不是又一个语音工具

市面上每一块都有成熟单点，但还没人把「聊透、自动开工、办完交付」做成同一套闭环。说到做的是完整治理，不是单点。

说了就记

按住说话，想到哪说到哪。随口一句「帮我记一下」立刻进账，不用专门开 app、不用组织语言。

先吃透，再办事

第一次聊一个项目，先读透结构、约定与关键文件，沉淀成持久知识底座，之后每次都带着对你项目的理解开聊。这是「说到」和「新开一个聊天窗口」的分水岭。

AI 真的在干活

接上你电脑上已登录的 AI——Codex、Claude Code、Cursor、Gemini CLI、Grok 等替它对话、思考、评估；动手改代码当前稳定路径是 Cursor Agent，Claude Code 已接入生产主流程、正在做最终真机收口。已订阅哪家用哪家，无需额外付费。

人拍板才算数

开工前给决策包三件套，做完说「等你验收」而不是「做完了」。合并、交付，永远你点头才算。

数据完全在你手里

没有开发者运营的云端后台，没有账号注册。对话、事项与账本保存在你自己的设备上；手机与电脑之间走你自己的局域网或你自行配置的加密组网。开发者无法访问、也不收集。

跨设备同一本账

手机上说的，电脑上看得见；电脑里记的，手机上盯得住。沟通天然是移动的，执行天然是固定的。

沟通面 ↔ 执行面

手机说话，电脑办事

沟通天然是移动的，执行天然是固定的。手机只做沟通——说话、看进展、点头确认。局域网连接不能审批 S2 / S3；你自己的加密组网远程面审批封顶 S2；合并、删除等 S3 始终只在电脑上。重活留在你的电脑上。

沟通面 · 你的手机

说话、看进展、点头确认。局域网不能批 S2 / S3；自行配置的远程面审批封顶 S2；合并与删除始终回电脑。随时在手，断了也不影响后端。

局域网或自行配置的加密组网

执行面 · 你的电脑

吃透项目、驱动 AI、后台办事、留存记忆。手机暂时离开，也不打断执行。

常见问题

先说清楚它不是什么

这是语音输入法吗？
不是。它不做「语音转文字再粘贴」，而是先吃透你的项目上下文，把每件事记成一本账，听懂了主动提议开工、自己把事办成。核心竞争力不在用哪个模型，而在上下文工程和人机协作流程。
是把我的项目上传到云端代跑吗？
不是。没有开发者运营的云端后台。重活在你自己的电脑上跑。你接入的第三方 AI（CLI 订阅或 API key）由你的电脑直接调用，开发者不经手、不可见。
需要什么前提？
在你的电脑（macOS / Windows / Linux）上运行「说到」桌面服务（开源免费）。按文档显式打开局域网访问后，可用手机浏览器扫码连接。AI 用你已有的 Claude Code、Codex、Cursor、Gemini CLI 等已登录工具——订阅是谁家的就用谁家的，无需额外付费。语音无需额外配置，浏览器即可用。
我的数据存在哪？
对话、事项与账本保存在你自己的设备上。手机与电脑之间走你自己的局域网或你自行配置的加密组网。你自行启用的云端语音、AI 上游和推送，由你的电脑直连第三方；开发者不接收这些数据。删除应用即删除手机端本地数据，电脑端由你自行管理。
它怎么知道「办完了」？
执行和检查都跑完，它会说「等你验收」——而不是「做完了」。它把成果按验收标准组织好（diff、测试、决策），你点头才算盖章销账。合并、交付，永远是你拍板才算数。
要花钱吗？
桌面服务免费。AI 的费用直接付给你选的厂商：用你已有的订阅（额度内零额外费用），或你自己的 API key 按量计费；每个任务有成本、时长、回合三重熔断。说到不加价、不经手、不代充。
它会替我 push 或开 PR 吗？
不会。它只在你项目里的独立 worktree 和 saydo/<任务> 分支上改代码；合并到你的分支要你用本机认证确认或自己动手；推送远端、开 PR 永远是你之后自己做的事。
