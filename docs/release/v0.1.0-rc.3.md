# SayDo CLI 0.1.0-rc.3

这是面向 macOS、Windows 与 Linux 的预发布快速启动包。无需克隆源码，安装 Node.js 22 后运行：

```sh
npm exec --yes --package=https://github.com/Octo-o-o-o/SayDo/releases/download/v0.1.0-rc.3/saydo-cli-0.1.0-rc.3.tgz -- saydo up
```

经常使用时可安装到自己的 npm 全局目录，再直接运行：

```sh
npm install --global https://github.com/Octo-o-o-o/SayDo/releases/download/v0.1.0-rc.3/saydo-cli-0.1.0-rc.3.tgz
saydo up
```

本候选替代未创建 Release 的 rc.2：修复了 Windows 上 `better-sqlite3` 被 pnpm 冗余触发本机编译、`.cmd` 安装入口被 Node 二次转义、管理员 token 新建状态目录无法归一到当前用户 SID 的问题，并消除了 Linux 恢复测试对事件写入时序的依赖及终止期 stdout `ECONNRESET` 泄漏。rc.2 标签与失败 Actions 记录继续保留，并按发布纪律不得移动或重跑。

当前包包含 SayDo daemon 与 Web 控制台。语音 pipeline、系统常驻服务及移动端生产配对不在这个包内；Windows 与 Linux 当前以前台方式运行。

Release 同时附带 `SHA256SUMS` 与包含源码输入摘要的 `release-metadata.json`。该标签由干净的公开仓快照构建；发布前在三个桌面系统通过源码绑定分发验收，发布后再从固定 URL 以空 npm cache、空全局 prefix、空 `SAYDO_HOME` 真实安装、启动、访问、停止并检查无 daemon 孤儿。
