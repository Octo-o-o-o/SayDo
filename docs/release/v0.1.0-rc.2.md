# SayDo CLI 0.1.0-rc.2

> 该候选从未产生 GitHub Release（首次 Actions 失败），下方安装命令的固定 URL 是 404——本文按发布纪律作为历史记录保留，不是可用的安装指引。当前可用版本见 [v0.1.0-rc.12.md](v0.1.0-rc.12.md)。

这是面向 macOS、Windows 与 Linux 的预发布快速启动包。无需克隆源码，安装 Node.js 22 后运行：

```sh
npm exec --yes --package=https://github.com/Octo-o-o-o/SayDo/releases/download/v0.1.0-rc.2/saydo-cli-0.1.0-rc.2.tgz -- saydo up
```

经常使用时可安装到自己的 npm 全局目录，再直接运行：

```sh
npm install --global https://github.com/Octo-o-o-o/SayDo/releases/download/v0.1.0-rc.2/saydo-cli-0.1.0-rc.2.tgz
saydo up
```

当前包包含 SayDo daemon 与 Web 控制台。语音 pipeline、系统常驻服务及移动端生产配对不在这个包内；Windows 与 Linux 当前以前台方式运行。

Release 同时附带 `SHA256SUMS` 与包含源码输入摘要的 `release-metadata.json`。该标签由干净的公开仓快照构建；发布前在三个桌面系统通过源码绑定分发验收，发布后再从固定 URL 以空 npm cache、空全局 prefix、空 `SAYDO_HOME` 真实安装、启动、访问、停止并检查无 daemon 孤儿。
