# SayDo CLI 0.1.0-rc.12

这是面向 macOS、Windows 与 Linux 的预发布快速启动包。无需克隆源码，安装 Node.js 22 后运行：

```sh
npm exec --yes --package=https://github.com/Octo-o-o-o/SayDo/releases/download/v0.1.0-rc.12/saydo-cli-0.1.0-rc.12.tgz -- saydo up
```

经常使用时可安装到自己的 npm 全局目录，再直接运行：

```sh
npm install --global https://github.com/Octo-o-o-o/SayDo/releases/download/v0.1.0-rc.12/saydo-cli-0.1.0-rc.12.tgz
saydo up
```

本候选取代 rc.11（全绿 available 的 Release）：rc.11 与 rc.12 之间为官网可用性文案、证据账本与实体门脚本修复（`10e1cde`：mutate 先入 index 再刷账本，及 release.yml 与发布门脚本随之更新），CLI 代码不变。rc.4 以来的累积修复（`.gitattributes` LF 合同、Linux 进程组 `ECONNRESET` 收口语义、tar 打包与验收竞态、进程组 SIGINT、实体门远端命令引号与 mutate 入 index 等）详见 `docs/review/2026-08-25-rc4-runtime-final-reimplementation-readback.md` §14-§17。rc.2-rc.11 各标签与其 Actions 记录继续保留，按发布纪律不移动、不重跑。

当前包包含 SayDo daemon 与 Web 控制台。语音 pipeline、系统常驻服务及移动端生产配对不在这个包内；Windows 与 Linux 当前以前台方式运行。

Release 同时附带 `SHA256SUMS` 与包含源码输入摘要的 `release-metadata.json`。按发布合同 v2（`0a2f290`），仓内 tracked manifest [`v0.1.0-rc.12-assets.json`](v0.1.0-rc.12-assets.json) 对 tgz 冻结 filename/entryCount/contentDigest 及 sourceRevision/buildId/protocolVersion，对 `SHA256SUMS` 与 `release-metadata.json` 只冻结 filename；bytes/sha256/npmIntegrity 等外壳字节交由 CI 自洽链与载荷级来源绑定承载，不再入 tracked manifest。该文件本身不是 Release asset。公开 tag 推送前要求 `release.yml` 对该 tag 全历史为零次 push run，并存在禁止 delete/update、无 bypass 的 active tag ruleset；workflow 全历史恰好一次且 `run_attempt=1`，并在开始、创建 Release 前、以及把 Release 标题改成版本名之前重读远端 tag SHA。availability 文案与证据/审计包按同一事务写入；Pages 先 preview 后 production。该标签由干净的公开仓快照构建；发布前在三个桌面系统通过源码绑定分发验收，发布后再从固定 URL 以空 npm cache、空全局 prefix、空 `SAYDO_HOME` 真实安装、启动、访问、停止并检查无 daemon 孤儿。本页描述的是发布候选合同，不是对外放行声明。
