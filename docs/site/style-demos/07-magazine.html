封面故事COVER STORY

从聊一句，到办完叫你：
一个完整的闭环

文 · 说到编辑部事实核校 · 四色账本阅读约需 4 分钟

早晨八点十二分，你在地铁里按住手机说了一句话：「把昨天说的导出功能做了，用 CSV。」没有打开任何应用，没有组织语言。这就是全部的开始。

接下来的事，和「新开一个聊天窗口」有本质不同。它先读透了你的项目——结构、约定与关键文件，沉淀成持久的知识底座——然后像采访一样一次问一个，把事聊透。①

规格是它的产物，不是你的输入。

火候够了，它主动提议开工，端出决策包三件套：成果预览、实施计划、预计花费与封顶，外加一份与计划同源生成的网页小样。看着具体的东西说「对 / 不对 / 调一下」，比凭空写需求容易一个数量级。

你说了「就这样」。它在你自己的电脑上放手去办：独立 git worktree 隔离，主工作区不会被碰；预算、时长、回合三重熔断，不会无人值守烧钱。你合上电脑去开会。

十点四十七分，手机震动：「做完了，测试全绿，等你验收。」它说「等你验收」，而不是「做完了」——合并、交付，永远你点头才算数。②

这一天你只做了两件事：说，和拍板。重活它来。

「市面上每一块都有成熟单点，
但还没人把它做成同一套闭环」

问 · 本刊记者答 · 说到
问

语音工具已经很多了，你不一样在哪？

语音只是入口。我做的是完整治理：聊透、自动开工、办完交付，三件事在同一个闭环里。单点工具把事「记下来」就结束了，我把事「办出着落」才算完。
问

用的哪家的 AI？要额外付费吗？

都不用。我接上你电脑上已登录的 AI——Codex、Claude Code、Cursor、Gemini CLI、Grok——替我对话、思考、评估；动手改代码当前稳定路径是 Cursor Agent。已订阅哪家用哪家。
问

AI 自己跑，出了问题谁负责？

你。人拍板才算数：开工前有决策包，做完说「等你验收」而不是「做完了」。合并、删除这类重操作，永远只在你的电脑上、由你点头。
问

手机上能做到什么程度？

沟通天然是移动的，执行天然是固定的。手机上说话、看进展、点头确认，审批封顶 S2；S3 重操作回电脑。手机暂时离开，也不打断执行。

编者的话FROM THE EDITOR

隐私不是承诺，是架构

读者来信常问：我的对话和项目数据，会传到你们的服务器吗？这里正式回答：我们没有服务器。

对话、事项与账本保存在你自己的设备上；手机与电脑之间走你自己的局域网或你自行配置的加密组网。没有账号体系，不埋点，不接入第三方统计或广告 SDK。你自行启用的云端语音与 AI 上游，由你的电脑直连第三方——开发者不接收这些数据。

无法访问，也不收集。这不是我们的自律，是我们的架构。
