說到賬本 · 卷一
卷之一 · 起 六步閉環

从聊一句，到办完叫你——你只管聊和拍板，重活它来。你点头，才算交付。

一开口聊

按住说话，想到哪说到哪。随口一句「帮我记一下」立刻进账。它带着对你项目的理解，像采访一样一次问一个，把事聊透。

二就绪决断

它判断火候够了，主动提议开工——规格是它的产物，不是你的输入。

三决策包

端出三件套请你拍板：成果预览、实施计划、预计花费与封顶，外加一份与计划同源的网页小样。

四你拍板

看着预览和计划说一句「就这样」，它就放手去办。合并、交付，永远你拍板才算数。

五后台执行

在你自己电脑上跑：独立 git worktree 隔离；预算、时长、回合三重熔断。你可以走开。

六叫你验收

执行和检查都跑完，它主动叫你。说「等你验收」，而不是「做完了」。

說到賬本 · 卷三
卷之三 · 轉 六義

不是又一个语音工具。市面上每一块都有成熟单点，但还没人把「聊透、自动开工、办完交付」做成同一套闭环。说到做的是完整治理。

说了就记

按住说话，想到哪说到哪。随口一句立刻进账，不用专门开 app、不用组织语言。

先吃透，再办事

第一次聊一个项目，先读透结构、约定与关键文件，沉淀成持久知识底座——这是和「新开一个聊天窗口」的分水岭。

AI 真的在干活

接上你电脑上已登录的 AI：Codex、Claude Code、Cursor、Gemini CLI、Grok。已订阅哪家用哪家，无需额外付费。

人拍板才算数

开工前给决策包三件套，做完说「等你验收」而不是「做完了」。合并、交付，永远你点头才算。

数据完全在你手里

没有云端后台，没有账号注册。对话、事项与账本保存在你自己的设备上，不埋点、不收集。

跨设备同一本账

手机只做沟通——说话、看进展、点头确认；重活留在你的电脑上，审批分级，S3 永远只在电脑。
