01
THE LOOP / 从聊一句到办完叫你

一个完整的闭环

你只管聊和拍板，重活它来。执行和检查都跑完，它主动叫你验收——你点头，才算交付。

01

开口聊

按住说话，想到哪说到哪。它像采访一样一次问一个，把事聊透。

02

就绪决断

火候够了，它主动提议开工。规格是它的产物，不是你的输入。

03

决策包

成果预览、实施计划、花费封顶，外加一份同源的网页小样。

04

你拍板

看着具体的东西说「就这样」。合并、交付，永远你点头才算。

05

后台执行

独立 worktree 隔离，预算/时长/回合三重熔断。你可以走开。

06

叫你验收

说「等你验收」，而不是「做完了」。证据在账，可复查可回溯。

02
FOUR TONES / 每件事都有归属和去向

四色账本，件件有着落

说过的话不再转头就忘。该等谁的、谁在办、办得怎么样——一眼看清，不靠脑子记。

朱

等你拍板

「导出用 CSV 还是 Excel？」——它把该你定的递到你面前，一句「就这样」就放行。

黛

你欠的动作

只有你能做的那部分，挂在你名下：回复那封设计稿确认邮件，今天 09:10 记的。

松

AI 正在办

重构登录模块，独立 worktree 里跑着，已 40 分钟。进展实时入账，随时可查。

灰

等外部回音

等第三方 API 配额审批。它不催不怨，回音一到，自动接着往下办。

03
WHY / 不是又一个语音工具

单点到处都是，闭环只此一家

没有它的时候

说过的话，转头就忘；答应的事，不知道办到哪了。该等谁的、谁在办、办得怎么样——全靠脑子记和来回翻聊天记录。

有了说到 →

聊透、自动开工、办完交付，同一套闭环。它接上你电脑上已登录的 AI——Codex、Claude Code、Cursor、Gemini CLI、Grok——已订阅哪家用哪家，无需额外付费。

隐私不是承诺，是架构。

对话、事项与账本保存在你自己的设备上。没有账号体系，不埋点，不接第三方统计或广告 SDK。手机与电脑之间走你自己的局域网或你自行配置的加密组网——开发者无法访问，也不收集。
