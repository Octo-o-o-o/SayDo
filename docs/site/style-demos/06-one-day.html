火候够了，它主动提议开工：成果预览、实施计划、预计花费与封顶，外加一份和计划同源生成的网页小样——先看最终长什么样，再说对不对。

规格是它的产物

09:05

一句「就这样」 拍板

看完小样，你说了三个字。它放手去办：独立 git worktree，主工作区不碰；预算、时长、回合三重熔断。你合上电脑，去开会。

合并、交付
永远你点头才算

整个上午，你没碰过一行代码，
也没写过一句需求。事在往前跑。
