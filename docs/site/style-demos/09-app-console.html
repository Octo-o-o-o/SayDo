一个完整的闭环

你只管聊和拍板，重活它来。执行和检查都跑完，它主动叫你验收——你点头，才算交付。

一

开口聊 INTERVIEW

按住说话，想到哪说到哪。它带着对你项目的理解，像采访一样一次问一个，把事聊透。

二

就绪决断 READY

火候够了，它主动提议开工——规格是它的产物，不是你的输入。

三

决策包 PKG ×3

成果预览、实施计划、预计花费与封顶，外加一份与计划同源生成的网页小样。

四

你拍板 QC GATE

看着具体的东西说「就这样」。合并、交付，永远你拍板才算数。

五

后台执行 UNATTENDED

独立 git worktree 隔离；预算、时长、回合三重熔断。你可以走开。

六

叫你验收 ACCEPT

说「等你验收」，而不是「做完了」。证据入账，可复查、可回溯。

不是又一个语音工具

市面上每一块都有成熟单点，但还没人把「聊透、自动开工、办完交付」做成同一套闭环。说到做的是完整治理，不是单点。

先吃透，再办事

第一次聊一个项目，先读透结构、约定与关键文件，沉淀成持久知识底座。这是和「新开一个聊天窗口」的分水岭。

AI 真的在干活

接上你电脑上已登录的 AI——Codex、Claude Code、Cursor、Gemini CLI、Grok。已订阅哪家用哪家，无需额外付费。

人拍板才算数

开工前给决策包三件套；做完说「等你验收」而不是「做完了」。合并、交付，永远你点头才算。

数据完全在你手里

不运营任何服务器，没有账号体系，不埋点。对话、事项与账本保存在你自己的设备上。
