你
它用的是哪家的 AI？要我再买一份订阅吗？
说
不用。它接上你电脑上已登录的 AI——Codex、Claude Code、Cursor、Gemini CLI、Grok 等替它对话、思考、评估；动手改代码当前稳定路径是 Cursor Agent，Claude Code 正在最终收口。已订阅哪家用哪家。
你
我的对话和项目数据，会传到你们服务器吗？
说
我们没有服务器。不运营任何云端后台，没有账号体系，不埋点。对话、事项与账本保存在你自己的设备上；手机与电脑之间走你自己的局域网或你自行配置的加密组网。开发者无法访问、也不收集。
你
手机上能用到什么程度？
说
沟通天然是移动的，执行天然是固定的。手机上说话、看进展、点头确认（审批封顶 S2）；合并、删除等 S3 重操作永远只在你的电脑上。手机暂时离开，也不打断执行。
