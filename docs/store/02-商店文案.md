## 应用描述(通用底稿)

说过的话,总是转头就忘;答应的事,不知道办到哪了。

【应用名】把「说」和「做」连起来:你开口说,它替你记成一本账——谁欠谁一个动作、哪件事等谁拍板、AI 正在替你办什么,一眼看清。聊成熟的事,它会问你要不要立起来持续盯;办完的事,盖章销账。

**为什么不一样**

- 【说了就记】按住说话,想到哪说到哪。随口一句"帮我记一下",立刻进账。
- 【一本账,不是一堆待办】每件事都有归属和去向:等你拍板的、你欠的动作、AI 在做的、等外部的,四色分明。
- 【AI 真的在干活】接上你电脑上已有的 AI(已订阅的 CLI 即可,无需额外付费),对话、整理、跟进都由它来。
- 【数据完全在你手里】没有云端服务器,没有账号注册。手机扫码连接你自己的电脑,数据只在你的设备和局域网里。
- 【跨设备同一本账】手机说的,电脑上看得见;电脑里记的,手机上盯得住。

**使用前提**:需在你的电脑(macOS)上运行 SayDo 桌面服务(开源免费),手机扫码即连。
